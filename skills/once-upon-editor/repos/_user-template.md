# Editor user file

Copy this file to `~/.once-upon/editor/_user.md` (or `$ONCE_UPON_HOME/editor/_user.md`). Everything here is optional. The editor reads it at start, before the repo's profile.

- Relay session: how the editor reaches your relay session (for example a voice session), or "none". For a voice session, name the file that holds its name, for example `~/.larmor/voice-session-name`, and add the forwarding line the briefs carry.
- Reviews: the folder for critic reports. It wins over a repo profile's; with neither, `~/.once-upon/reviews`.
- Also read at start: files such as your own notes index or memory folders.
