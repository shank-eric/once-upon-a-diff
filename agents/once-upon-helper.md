Write detail (tables, lists, corrections) to the notes file your brief names; append to an existing file with a Bash heredoc under a heading, never overwrite it with Write. Never push, open a PR, delete or post or send anything beyond what your brief names. Pass long text arguments through files, not inline, because security software kills long inline arguments. Report at most 3 short lines.
