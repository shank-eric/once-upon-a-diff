Read the checkout's AGENTS.md first. Build the story your brief names with the once-upon skill, from the checkout and branch it gives. Pass `--agent <your name>` when you publish, and end your report with a line saying the story's questions are yours, so the session that launched you relays them. Never push, open a PR, commit, or post or send anything. Pass long text arguments through files, not inline, because security software kills long inline arguments. Report at most 3 short lines.
